# Implementation plan

## Integration contract

**Entrypoint:** `taskboard/cmd/taskboard/main.go`

**Startup / dependency order (SPEC + architecture):**

- Entrypoint `taskboard/cmd/taskboard/main.go` parses configuration settings via `taskboard/internal/config/config.go`.
- Based on DB driver setting, creates SQLite store via `taskboard/internal/store/sqlite.go` or PostgreSQL store via `taskboard/internal/store/postgres.go`.
- Calls schema initialization with transactional advisory locks for PostgreSQL setup.
- Passes store instance and embedded assets from `taskboard/web/assets.go` to router constructor in `taskboard/internal/web/app.go`.
- Registers static asset serving and REST API endpoints in `taskboard/internal/web/api.go`.
- Starts HTTP server listening on configured host and port, supporting graceful SIGTERM shutdown.

**HTTP routes (SPEC verbatim):**

| Method | Path |
|--------|------|
| GET | `/api/health` |
| GET | `/api/ready` |
| GET | `/api/projects` |
| POST | `/api/projects` |
| DELETE | `/api/projects/{project_id}` |
| GET | `/api/projects/{project_id}/tasks` |
| POST | `/api/projects/{project_id}/tasks` |
| PATCH | `/api/tasks/{task_id}` |
| DELETE | `/api/tasks/{task_id}` |

**Per-file exports (from architecture.md):**

- `taskboard/internal/config/config.go`: Config struct, LoadConfig function
- `taskboard/internal/model/model.go`: Project struct, Task struct, Status and Priority types, TaskFilter struct, ValidateProject, ValidateTask functions
- `taskboard/internal/store/store.go`: Store interface, ErrNotFound and repository error constants, DDL schema constants
- `taskboard/internal/store/sqlite.go`: SQLiteStore struct, NewSQLiteStore function
- `taskboard/internal/store/postgres.go`: PostgresStore struct, NewPostgresStore function
- `taskboard/internal/store/store_test.go`: SQLite integration and unit tests for Store using isolated t.TempDir() database files (never the runtime taskboard.db)
- `taskboard/internal/store/postgres_integration_test.go`: Postgres integration tests using container or DSN
- `taskboard/web/assets.go`: Embedded FS assets (FS)
- `taskboard/web/templates/index.html`: UI Kanban HTML template
- `taskboard/web/static/app.js`: Frontend JS dynamics, fetch calls, status updates, filters
- `taskboard/web/static/style.css`: UI styles and column responsive design
- `taskboard/internal/web/app.go`: App struct, NewApp, Server lifecycle
- `taskboard/internal/web/api.go`: HTTP REST API handlers (projects, tasks, status, health, ready)
- `taskboard/internal/web/app_test.go`: Tests for HTTP routing and server initialization
- `taskboard/internal/web/api_test.go`: Unit/integration tests for REST API routes
- `taskboard/internal/web/ui_content_test.go`: Unit tests asserting embedded UI assets and templates render properly
- `taskboard/cmd/taskboard/main.go`: main function entrypoint
- `taskboard/package.json`: E2E test dependencies and npm scripts
- `taskboard/package-lock.json`: Locked npm dependency tree
- `taskboard/playwright.config.ts`: Playwright test configuration
- `taskboard/playwright/taskboard.spec.ts`: E2E browser automation tests for UI
- `taskboard/Dockerfile`: Multi-stage Docker build recipe
- `taskboard/.dockerignore`: Build context exclusions for Docker
- `taskboard/deploy/k8s/deployment.yaml`: Kubernetes Deployment configuration
- `taskboard/deploy/k8s/service.yaml`: Kubernetes Service configuration
- `taskboard/deploy/k8s/secret.example.yaml`: Kubernetes Secret template
