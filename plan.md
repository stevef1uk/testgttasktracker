# Implementation plan

## Integration contract

**Entrypoint:** `taskboard/cmd/taskboard/main.go`

**Startup / dependency order (SPEC + architecture):**

- Load configuration from environment (internal/config)
- Initialize database store and apply schema setup (internal/store)
- Construct application and register HTTP API handlers (internal/web)
- Start HTTP server on configured host:port
- Handle graceful shutdown on SIGTERM/SIGINT

**HTTP routes (SPEC verbatim):**

| Method | Path |
|--------|------|
| GET | `/api/health` |
| GET | `/api/ready` |
| GET | `/api/projects` |
| POST | `/api/projects` |
| DELETE | `/api/projects/{project_id}` |
| GET | `/api/projects/{project_id}/tasks` |
| POST | `/api/projects/{project_id}/tasks` |
| PATCH | `/api/tasks/{task_id}` |
| DELETE | `/api/tasks/{task_id}` |

**Per-file exports:** see `architecture.md` per-file ownership table; use only names documented there.
