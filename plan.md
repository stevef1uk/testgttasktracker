### ta-93p: taskboard/internal/config/config.go
- Scope: `Config` struct and `LoadConfig() (Config, error)` reading the five TASKBOARD_* variables.
- Architecture: SPEC section 4; architecture.md config ownership.
- Interfaces: `type Config struct{DBDriver, DBPath, DatabaseURL, Host string; Port int}`, `func LoadConfig() (Config, error)`.
- Depends on: taskboard/go.mod (ta-92w)
- Consumed by: taskboard/cmd/taskboard/main.go (phase-1-app)
- Acceptance: driver must be exactly sqlite or postgres; postgres requires a nonempty DATABASE_URL; port must be integer 1-65535; errors never echo the URL.
- Verify: `cd taskboard && go test ./internal/config`

### ta-i6d: taskboard/internal/model/model.go
- Scope: Project and Task structs; name trimmed 1-80 code points; title trimmed 1-120 code points; description at most 1000 code points; status in {todo, doing, done} default todo; priority in {low, medium, high} default medium.
- Architecture: SPEC section 5 limits; utf8.RuneCountInString for length checks.
- Interfaces: Project, Task structs; validation helpers for name, title, description, status, priority.
- Depends on: taskboard/go.mod (ta-92w)
- Consumed by: taskboard/internal/store/sqlite.go, taskboard/internal/store/store.go
- Acceptance: boundary cases at 80/81 name runes, 120/121 title runes, 1000/1001 description runes; blank-after-trim rejected; unknown enum rejected; multi-byte runes counted as one.
- Verify: `cd taskboard && go test ./internal/model`

### ta-xea: taskboard/internal/store/store.go
- Scope: `Store` interface with Ping and Close; DDL constants for projects and tasks (SchemaSQLite) with ON DELETE CASCADE, UTC timestamp defaults, and project_id index; repository error values (ErrNotFound).
- Architecture: SPEC section 5; architecture.md store ownership.
- Interfaces: `type Store interface{Ping(ctx) error; Close() error}`, `SchemaSQLite` constant, ErrNotFound.
- Depends on: taskboard/internal/model/model.go (ta-i6d)
- Consumed by: taskboard/internal/store/sqlite.go, taskboard/internal/web/app.go (phase-1-app)
- Acceptance: DDL is dialect-neutral CREATE IF NOT EXISTS; no PostgreSQL syntax in this file.
- Verify: `cd taskboard && go test ./internal/store`

### ta-zmd: taskboard/internal/store/sqlite.go
- Scope: SQLite Store with CRUD for projects and tasks, foreign keys enabled on every pooled connection (DSN configuration), 5000 ms busy timeout, `?` placeholders, parameterized filters, ascending id ordering, UTC RFC3339 timestamps.
- Architecture: SPEC section 5 (per-connection FK enforcement, busy timeout, no interpolated user input).
- Interfaces: `NewSQLiteStore(path string) (*SQLiteStore, error)`; methods implement CRUD and ListTasks with status and priority filters.
- Depends on: taskboard/internal/store/store.go (ta-xea), taskboard/internal/model/model.go (ta-i6d)
- Consumed by: taskboard/internal/store/store_test.go (phase-1-app)
- Acceptance: cascade delete removes tasks; FK violation on unknown project returns error; reopen preserves rows; PATCH preserves omitted fields; filters combine with AND.
- Verify: `cd taskboard && go test ./internal/store`
