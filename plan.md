# Implementation plan

## Integration contract

**Entrypoint:** `taskboard/cmd/taskboard/main.go`

**Startup / dependency order (SPEC + architecture):**

- Parses CLI flags / loads configuration via config.LoadConfig().
- Selects database driver based on TASKBOARD_DB_DRIVER (sqlite or postgres) and initializes NewSQLiteStore or NewPostgresStore.
- Creates web application instance passing the selected store.
- Registers static file handlers serving assets embedded in `taskboard/web/assets.go`.
- Starts HTTP server on configured host and port.
- Handles graceful SIGINT/SIGTERM shutdown.
- Start TaskBoard server locally with default SQLite configuration:
- Verify liveness and readiness endpoints:

**HTTP routes (SPEC verbatim):**

| Method | Path |
|--------|------|
| GET | `/api/health` |
| GET | `/api/ready` |
| GET | `/api/projects` |
| POST | `/api/projects` |
| DELETE | `/api/projects/{project_id}` |
| GET | `/api/projects/{project_id}/tasks` |
| POST | `/api/projects/{project_id}/tasks` |
| PATCH | `/api/tasks/{task_id}` |
| DELETE | `/api/tasks/{task_id}` |

**Per-file exports (from architecture.md):**

- `taskboard/internal/config/config.go`: Config struct, LoadConfig function
- `taskboard/internal/model/model.go`: Project struct, Task struct, Status and Priority types/constants, TaskFilter struct, ValidateProject, ValidateTask functions
- `taskboard/internal/store/store.go`: Store interface, ErrNotFound and repository error constants, DDL schema constants
- `taskboard/internal/store/sqlite.go`: SQLiteStore struct, NewSQLiteStore function
- `taskboard/internal/store/postgres.go`: PostgresStore struct, NewPostgresStore function
- `taskboard/web/assets.go`: FS embed variable
- `taskboard/internal/web/app.go`: App struct, NewApp function
- `taskboard/internal/web/api.go`: API route handler methods on App struct
- `taskboard/cmd/taskboard/main.go`: main function
