# Implementation plan — phase-3-browser

Active phase: phase-3-browser (Playwright integration and browser QA).
Scope: the four required_files below only. Later phases (backend, frontend, Docker, k8s) are out of scope for this plan.

## Contract decisions

- Playwright baseURL default is `http://127.0.0.1:8080` (architecture.md, playwright.config.ts row). Any cached content using `http://app:8080` is superseded and must be replaced.
- Test runner command for this phase: `cd taskboard && go test ./... && ./node_modules/.bin/playwright test --config playwright.config.ts playwright`.
- No node_modules, browser binaries, or database files are committed.
