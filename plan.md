# Implementation plan

Active delivery phase: phase-3-browser (Playwright integration and browser QA). Only the four required_files below are in scope for this phase.

## Bead map

### ta-4r9: taskboard/package.json
- Scope: Node manifest for the browser test toolchain. Declares `@playwright/test` as a development dependency only. No npm build scripts and no frontend bundler.
- Architecture: architecture.md "Planned file layout" (Node manifest) and phase-3-browser required_files.
- Depends on: none (first Node bead; the lockfile is generated from this manifest).
- Consumed by: taskboard/package-lock.json, taskboard/playwright.config.ts, taskboard/playwright/taskboard.spec.ts.
- Acceptance:
  - File exists at taskboard/package.json and parses as valid JSON.
  - `@playwright/test` appears only under devDependencies.
  - No `build`, `bundle`, or other frontend build scripts are declared (SPEC Phase 3).
  - Verify: `cd taskboard && go test ./... && ./node_modules/.bin/playwright test --config playwright.config.ts playwright`
  - Bead ta-4r9 is closed only after verification passes.

### ta-1jk: taskboard/package-lock.json
- Scope: npm-generated lockfile committed alongside taskboard/package.json. Generated by running npm install --ignore-scripts during implementation, never handwritten.
- Architecture: architecture.md "Planned file layout" (Node lockfile) and phase-3-browser required_files.
- Depends on: taskboard/package.json (ta-4r9).
- Consumed by: Playwright runs in the Verify command; Node dependencies must be installed before test review.
- Acceptance:
  - File exists at taskboard/package-lock.json and is produced by npm, with lockfileVersion present.
  - Resolves @playwright/test pinned by taskboard/package.json.
  - Verify: `cd taskboard && go test ./... && ./node_modules/.bin/playwright test --config playwright.config.ts playwright`
  - Bead ta-1jk is closed only after verification passes.

### ta-aug: taskboard/playwright.config.ts
- Scope: minimal Playwright configuration. Sets baseURL to http://127.0.0.1:8080 and points testDir at the playwright/ directory. It does not start a webServer, because the TaskBoard server is already running on that address.
- Architecture: architecture.md line 57 and SPEC.md Phase 3 config rules (preserve a canonical generated config if one exists; otherwise create a minimal compatible one).
- Depends on: taskboard/package.json (ta-4r9) for the @playwright/test types.
- Consumed by: taskboard/playwright/taskboard.spec.ts (through the `--config` flag in Verify).
- Acceptance:
  - File exists at taskboard/playwright.config.ts and exports a default config.
  - use.baseURL equals http://127.0.0.1:8080.
  - testDir resolves to the playwright/ directory containing taskboard.spec.ts.
  - No duplicate or wrapper Playwright configs are created.
  - Verify: `cd taskboard && go test ./... && ./node_modules/.bin/playwright test --config playwright.config.ts playwright`
  - Bead ta-aug is closed only after verification passes.

### ta-ud0: taskboard/playwright/taskboard.spec.ts
- Scope: browser E2E specs against the running server. Covers the initial shell, project and task creation through browser controls, Move forward from To Do to Doing to Done, delete, and the high-priority filter with reset (architecture.md line 135).
- Architecture: architecture.md line 58 and line 135; SPEC.md "Playwright E2E" section and Phase 3 gate.
- Depends on: taskboard/playwright.config.ts (ta-aug) and the already-running TaskBoard server on 127.0.0.1:8080.
- Consumed by: phase QA gate (`playwright test` in Verify).
- Acceptance:
  - File exists at taskboard/playwright/taskboard.spec.ts.
  - At least one test performs real clicks and selections and asserts DOM or API state changes after each action.
  - Tests cover: initial shell render; create project; create task; Move forward To Do -> Doing -> Done; delete task; high-priority filter applied and then reset.
  - No trivial always-pass tests (no `expect(true)`, empty test bodies, or import-only tests).
  - Test names map to the SPEC Playwright E2E behaviors listed above.
  - QA verifies the rendered screen performs at least one user action before reporting all_passed.
  - Verify: `cd taskboard && go test ./... && ./node_modules/.bin/playwright test --config playwright.config.ts playwright`
  - Bead ta-ud0 is closed only after verification passes.
